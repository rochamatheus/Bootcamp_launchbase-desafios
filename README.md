# Bootcamp\_launchbase\_desafios

Este projeto foi criado como parte do desafio "Momento de Conhecimento" durante a quarentena, organizado pela Rocketseat. Ele é focado no aprendizado e na prática dos conceitos fundamentais de JavaScript, abordando a primeira fase do curso.

## Tópicos do Desafio (Fase 1)

Os desafios propostos cobrem os seguintes tópicos essenciais de JavaScript:

  * **Ensinando sintaxe:** Introdução à estrutura básica do JavaScript.
  * **Condicionais:** Utilização de `if`, `else if` e `else` para controle de fluxo.
  * **Operadores relacionais e comparativos:** Prática com operadores como `==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`.
  * **Operadores lógicos e aritméticos:** Uso de `&&`, `||`, `!`, e operadores matemáticos `+`, `-`, `*`, `/`, `%`.
  * **Objetos e Vetores:** Manipulação de estruturas de dados como objetos (JSON) e arrays.
  * **Estruturas de repetição:** Implementação de `for`, `while`, e `for...of` para iterar sobre dados.
  * **Escopos:** Entendimento e aplicação de escopos globais e locais.
  * **Booleanos:** Trabalho com valores lógicos `true` e `false`.

## Estrutura do Projeto

O projeto é composto por diversos arquivos `.js`, cada um representando um desafio ou exercício específico. Os arquivos são:

  * `aposentadoria.js`
  * `banco.js`
  * `calcula.js`
  * `empresa.js`
  * `imcalculo.js`
  * `tecno.js`
  * `tecnologia.js`

Cada arquivo aborda um ou mais dos tópicos listados acima, permitindo a prática e a consolidação dos conhecimentos.

## Como Executar

Para rodar os arquivos, basta ter o Node.js instalado. Navegue até a pasta do projeto e execute o arquivo desejado no terminal. Por exemplo:

```bash
node aposentadoria.js
```
